# קבלת סחורה

אפליקציה (PWA) לקבלת סחורה, הזמנות ומחירון שבועי של פירות וירקות.

- המסכים מתארחים כאן ב-GitHub Pages.
- הנתונים נשמרים בגיליון Google של העסק, דרך Google Apps Script (`Code.gs`).
- הכתובת של השרת מוגדרת ב-`index.html` במשתנה `API_URL`.

אחרי שינוי בקבצים: לעדכן את `CACHE` ב-`sw.js` (למשל `kabala-v2`) כדי שהטלפונים יקבלו את הגרסה החדשה.
